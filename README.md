# CALM Architecture as Code

My work from the [FINOS CALM](https://calm.finos.org) beginner tutorials. CALM is an open standard for describing software architecture as JSON, so it can be validated, version-controlled and turned into diagrams like code.

## What's in here

A model of a **customer authentication system**: a customer, a login service and its database, plus how they connect (protocols, ports) and metadata like ownership and SLA tier. It's validated against the CALM 1.3 schema.
